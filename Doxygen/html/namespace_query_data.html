Detailed Description

High-level wrapper for SQLite CRUD operations.

  • Provides a simplified interface for common database interactions, automatically handling statement preparation, parameter binding, and result set mapping.

Updates rows in a database table.

Supports two modes:

  1. Direct value update: Set columns to new values
  2. Math operation: Apply arithmetic to existing values
Parameters
dbNameName/path of the database file
tableName of the table to update
whereColumnsColumns to match for selection
whereValuesValues to match in those columns
updateColumnsColumns to update
updateValuesNew values for those columns
mathValueOptional arithmetic operation (e.g., "+ 5.0")
Returns
true if update successful, false otherwise
// Direct update
QueryData::updateRows("souvenirs.db", "souvenirs",
{"college", "item"}, {"UCLA", "T-Shirt"},
{"price"}, {29.99});
// Math operation (increase price by 5)
QueryData::updateRows("souvenirs.db", "souvenirs",
{"college"}, {"UCLA"},
{"price"}, {}, "+ 5.0");
