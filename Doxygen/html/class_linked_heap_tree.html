Detailed Description

template<typename Key, typename Value>
class LinkedHeapTree< Key, Value >

Min-heap priority queue using linked binary tree.

A min-heap implementation where the element with the smallest key is always at the root. Uses a linked tree structure instead of array-based storage, allowing for position-based operations.

Template Parameters
KeyComparable type for heap ordering (e.g., double for distances)
ValueData type stored with each key (e.g., int for campus index)

Data Structure Analysis:

  • Type: Binary Min-Heap (complete binary tree)
  • Storage: Linked nodes with parent/child pointers
  • Ordering: Parent key <= child keys (min-heap property)

Usage in TourPlanner:

LinkedHeapTree<double, int> heap;
for (int i = 0; i < campuses.size(); i++) {
if (!visited[i])
heap.insert(distances[current][i], i);
}
int nearest = heap.removeMin(); // Get closest campus index

template<typename Key, typename Value>
Node * LinkedHeapTree< Key, Value >::findNode ( int index)
inlineprotected

Finds node at given index using bit manipulation.

Uses the binary representation of the index to navigate the tree. Each bit (after the leading 1) represents a left (0) or right (1) decision.

Parameters
index1-based index of the node
Returns
Pointer to the node at that index

Time Complexity: O(log n) - depth of tree

Algorithm:

  • Index 1 = root
  • Index 2 = root->left, Index 3 = root->right
  • For index i: parent is at i/2
  • Bit pattern determines path: 0=left, 1=right
