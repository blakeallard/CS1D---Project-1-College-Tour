Utility functions for administrative operations.

Contains helper functions for processing file uploads and merging database content during administrative imports.

bool Helpers::getDatabaseFromRequest ( crow::request req)

Extracts and saves database file from HTTP request.

Parses multipart form data from the request to extract an uploaded database file. Saves the file to Databases/uploaded.db for subsequent merging operations.

Parameters
reqHTTP request containing multipart form data
Returns
true if extraction successful, false otherwise
Note
Expected form field name varies based on implementation

Merges data from one database into another.

Copies rows from the source database/table into the destination database/table. Supports unique constraint checking to prevent duplicate entries.

Parameters
mainDBNamePath to destination database
otherFilePath to source database (typically uploaded.db)
mergeIntoTableTable name in destination database
mergeFromTableTable name in source database
isUniqueIf true, only merge rows with unique key values
mergeIntoColumnsColumns to insert into (empty for all)
mergeFromColumnsColumns to read from (empty for all)
uniqueIntoColumnColumn in destination for uniqueness check
uniqueFromColumnColumn in source for uniqueness check
Returns
true if merge successful, false otherwise
Note
Used for importing new campuses and souvenirs via admin interface
// Merge distances from uploaded file
Helpers::mergeDatabases("Databases/distances.db",
"Databases/uploaded.db",
"distances", "distances");
// Merge unique colleges
Helpers::mergeDatabases("Databases/distances.db",
"Databases/uploaded.db",
"colleges", "distances",
true, {}, {},
"college", "starting_college");
