Detailed Description

Template-based min-heap implementation using linked tree structure.

This file implements a min-heap priority queue using a linked binary tree structure. The heap is used by TourPlanner for efficient nearest-neighbor selection during tour path calculation.

Key Features:

  • Generic template supporting any key/value types
  • O(log n) insert, remove, and key updates
  • O(1) minimum access
  • Position-based API for direct node manipulation
