Detailed Description

template<typename Key, typename Value>
class LinkedHeapTree< Key, Value >::Position

Handle for accessing and manipulating heap entries.

Provides an abstraction for interacting with heap entries without direct node manipulation. Supports tree traversal via left(), right(), and parent() methods.
