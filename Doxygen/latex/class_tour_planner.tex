\doxysubsection{Detailed Description}
Calculates optimal tour routes through college campuses. 

This class provides static methods for computing efficient tour paths using a combination of greedy nearest-\/neighbor algorithm and 2-\/opt local optimization. The algorithm works as follows:\+


\begin{DoxyEnumerate}
\item Build a distance matrix from database queries
\item Use greedy nearest-\/neighbor to build initial route (O(n²))
\item Apply 2-\/opt optimization to improve route locally (O(n²) per iteration)
\end{DoxyEnumerate}

\begin{DoxyNote}{Note}
Uses \doxylink{class_linked_heap_tree}{Linked\+Heap\+Tree} for efficient minimum distance selection
\end{DoxyNote}
Data Structures Used:\+
\begin{DoxyItemize}
\item vector$<$vector$<$double$>$$>$:\+ 2D distance matrix (adjacency matrix)
\item map$<$string, int$>$:\+ Campus name to index mapping
\item \doxylink{class_linked_heap_tree}{Linked\+Heap\+Tree}:\+ Min-\/heap for nearest neighbor selection
\item vector$<$bool$>$:\+ Visited campus tracking
\item vector$<$int$>$:\+ Route as sequence of campus indices 
\end{DoxyItemize}

2-\/opt local optimization for tour improvement 

2-\/opt local optimization

Iteratively improves the tour by checking if reversing any subsequence would reduce total distance. This is a local optimization that can escape some suboptimal greedy choices.

Algorithm:\+ For each pair of non-\/adjacent edges (A-\/B) and (C-\/D):\+
\begin{DoxyItemize}
\item Compare current distance:\+ A→B + C→D
\item With proposed swap:\+ A→C + B→D (reversing B...C segment)
\item If proposed is shorter, reverse the segment Repeat until no improvement found.
\end{DoxyItemize}

Recursive greedy nearest-\/neighbor tour construction. 

Recursive greedy nearest-\/neighbor traversal.

Starting from the current campus, recursively visits the nearest unvisited campus until all campuses have been visited. Uses a min-\/heap (\doxylink{class_linked_heap_tree}{Linked\+Heap\+Tree}) for efficient nearest neighbor selection.

Algorithm:\+
\begin{DoxyEnumerate}
\item Add current campus to route and mark as visited
\item Build min-\/heap of distances to unvisited campuses
\item If heap is empty (base case), return
\item Extract minimum, recurse to that campus
\end{DoxyEnumerate}
