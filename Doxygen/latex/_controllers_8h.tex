\doxysubsection{Detailed Description}
REST API controllers for the College Tour application. 

This file defines controller structs that handle HTTP requests for different API endpoints. Each controller follows CRUD pattern with read, create, patch, and remove operations.

Controllers use the Crow HTTP framework for request/\+response handling.
