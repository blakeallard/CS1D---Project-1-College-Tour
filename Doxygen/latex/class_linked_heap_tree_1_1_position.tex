class Linked\+Heap\+Tree$<$ Key, Value $>$::\+\+Position}
Handle for accessing and manipulating heap entries. 

Provides an abstraction for interacting with heap entries without direct node manipulation. Supports tree traversal via \doxylink{class_linked_heap_tree_1_1_position_abec7e308e53138135f8c21469059176a}{left()}, \doxylink{class_linked_heap_tree_1_1_position_a36a9cd7d1b0357ad2985f0e520d898fc}{right()}, and \doxylink{class_linked_heap_tree_1_1_position_acda37d9e83c1862b356c0bb72e2e46d2}{parent()} methods.
