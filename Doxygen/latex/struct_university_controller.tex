\doxysubsection{Detailed Description}
Handles university/\+campus-\/related API endpoints. 

Endpoints:\+
\begin{DoxyItemize}
\item GET /\+api/\+\+University/\+all -\/ List all campuses with distances from Saddleback
\item GET /\+api/\+\+University/\+from-\/\{campus\} -\/ List campuses reachable from specified campus
\item GET /\+api/\+\+University/\+\{campus\} -\/ Get souvenirs for a specific campus
\item POST /\+api/\+\+University/\+import -\/ Import new campus data 
\end{DoxyItemize}
