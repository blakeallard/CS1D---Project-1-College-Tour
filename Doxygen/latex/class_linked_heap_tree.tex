\subsubsection*{template$<$typename Key, typename Value$>$\newline
class Linked\+Heap\+Tree$<$ Key, Value $>$}
Min-\/heap priority queue using linked binary tree. 

A min-\/heap implementation where the element with the smallest key is always at the root. Uses a linked tree structure instead of array-\/based storage, allowing for position-\/based operations.


\begin{DoxyTemplParams}{Template Parameters}
{\em Key} & Comparable type for heap ordering (e.\+g., double for distances) \\
\hline
{\em Value} & Data type stored with each key (e.\+g., int for campus index)\\
\hline
\end{DoxyTemplParams}
Data Structure Analysis:\+
\begin{DoxyItemize}
\item Type:\+ Binary Min-\/\+Heap (complete binary tree)
\item Storage:\+ Linked nodes with parent/\+child pointers
\item Ordering:\+ Parent key \texorpdfstring{$<$}{<}= child keys (min-\/heap property)
\end{DoxyItemize}
