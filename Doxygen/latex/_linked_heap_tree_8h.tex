\doxysubsection{Detailed Description}
Template-\/based min-\/heap implementation using linked tree structure. 

This file implements a min-\/heap priority queue using a linked binary tree structure. The heap is used by \doxylink{class_tour_planner}{Tour\+Planner} for efficient nearest-\/neighbor selection during tour path calculation.

Key Features:\+
\begin{DoxyItemize}
\item Generic template supporting any key/\+value types
\item O(log n) insert, remove, and key updates
\item O(1) minimum access
\item Position-\/based API for direct node manipulation
\end{DoxyItemize}
